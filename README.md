# Crônicas de Aetherion — Portal do jogador

Ficha estática responsiva, sem dependências externas. Publicar com Settings → Pages → Deploy from a branch → main / (root). O navegador consulta data.json a cada 20 segundos enquanto a aba estiver visível. Catálogos devem ser atualizados junto com os dados, em commit único. Não publicar arquivos do Mestre nem credenciais. Dados da primeira versão: V539/C747.
